# Register API

Create a customer account. No authentication required.

**Method:** `POST`  
**Local URL:** `http://localhost:4000/api/v1/auth/register`

## Headers

```http
Content-Type: application/json
Accept: application/json
```

## Request body

```json
{
  "email": "customer@example.com",
  "password": "Example123!",
  "firstName": "App",
  "lastName": "User",
  "phone": "+27 82 123 4567",
  "marketingConsent": false,
  "acceptTerms": true
}
```

| Field | Required | Validation |
| --- | --- | --- |
| `email` | Yes | Valid email, maximum 254 characters; trimmed and lowercased. |
| `password` | Yes | 8–128 characters with at least one letter and one number. |
| `firstName` | Yes | 1–80 characters after trimming. |
| `lastName` | Yes | 1–80 characters after trimming. |
| `phone` | No | 7–20 characters: digits, spaces, parentheses or hyphens, with an optional leading `+`. |
| `marketingConsent` | No | Boolean; defaults to false. |
| `acceptTerms` | Yes | Must be `true`. |

## Success response — 201 Created

Illustrative response; tokens and IDs are generated by the server:

```json
{
  "tokenType": "Bearer",
  "accessToken": "<accessToken>",
  "expiresIn": 900,
  "refreshToken": "<refreshToken>",
  "refreshTokenExpiresAt": "<ISO timestamp>",
  "user": {
    "id": "<user UUID>",
    "email": "customer@example.com",
    "firstName": "App",
    "lastName": "User",
    "phone": "+27 82 123 4567",
    "role": "CUSTOMER"
  }
}
```

Registration signs the user in automatically. Store the returned access and refresh tokens securely; `expiresIn` is seconds and depends on server configuration. Send `Authorization: Bearer <accessToken>` on authenticated requests.
